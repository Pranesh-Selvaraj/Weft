# Examples

Small, real artifacts that show the contract in use.

Planned examples, added as the corresponding pieces land:

- `examples/starter.weft/` — a hand-written design file small enough to read in one sitting: one page, a frame, text, a shape, a token set.
- `examples/extracted-page/` — a snapshot frame captured from a running page, with annotations and an agent transcript.
- `examples/host-app/` — a tiny product page used to demonstrate extraction into Weft and implementation back out.

Examples are test fixtures as well as documentation: CI should open them, validate them against the schema, and fail if they drift.
